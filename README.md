# Memory Islands

Memory Islands is a Vue 3 + Vite shared memory board. Supabase stores the memory records and uploaded images so different devices can see the same content.

## Development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and add the Supabase URL and publishable/anon key. See `docs/SUPABASE_SETUP.md` for database, Storage, RLS, Realtime, and GitHub Pages setup.
